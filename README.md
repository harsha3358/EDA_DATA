# Loan Data Exploration

An exploratory analysis of roughly 30,000 loan records, created to turn a large spreadsheet into understandable patterns and visual findings.

## Why it matters

Lending data is difficult to use when it remains a raw table. This project demonstrates how analysis can reveal customer groups, borrowing behavior, risk indicators, and questions worth investigating.

## What is included

- Loan data in CSV format
- Data cleaning and exploration
- Comparisons across important variables
- Visualizations for communicating findings

## Technology

Python data-analysis tools, Jupyter Notebook, and CSV data.

Open the notebooks, confirm the dataset path, and run the cells in order. This is an educational analysis, not a production credit-decision system.
